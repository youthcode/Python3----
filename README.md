# Python爬虫教程

这是一个Python爬虫学习项目，包含了多个爬虫示例和相关技术的实践。

## 环境配置

本项目使用Python虚拟环境，依赖包括：
- requests
- pyquery
- lxml
- cssselect

## 安装步骤

1. 创建虚拟环境：
```
python3 -m venv venv
```

2. 激活虚拟环境：
```
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate  # Windows
```

3. 安装依赖：
```
pip install -r requirements.txt
```

## 项目结构

- 1-爬虫基础入门：爬虫基础知识和入门示例
- 2-页面解析和数据存储：各种数据提取和存储方法的实现
